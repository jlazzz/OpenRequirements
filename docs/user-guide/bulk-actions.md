# Changing many items at once

In List view, tick the items to change. The box in the header ticks every item shown. Then choose:

- **Set a field…** gives one field the same value on every ticked item. Leave the value empty to clear the field. Each item that does not have that value yet gets a new version; nothing else about it changes. Add a reason if you like: it shows in each item's history.
- **Move to…** moves the items into a folder of the same set, or to its top level. They go last, in the order they have now.
- **Delete** removes them from the project. Their history is kept, their IDs are never reused, and each can be restored from **Deleted items**.

Up to 500 items at a time. Either every item is changed or, if one cannot be, none is: the message names the item.

Setting a field is refused while you have an unsaved draft of one of the items. Save or discard the draft first.

## Dark mode

The button left of your name in the top bar switches between light and dark. Until you choose, the app follows your computer's setting. Printing always uses light.
