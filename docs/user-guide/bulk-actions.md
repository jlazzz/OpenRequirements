# Moving and changing many items at once

## Drag and drop

In the explorer and in List view, drag a folder or item to reorder it or move it:

- Drop on the **top or bottom edge** of a row to place it just before or after that row, in that row's folder.
- Drop on the **middle** of a folder to put it inside, last. Drop on the middle of an item to make it a **child item** of that item.
- Drop on a **set** in the explorer to move it to the top level of the set.

A line or frame shows where it will land; nothing shows when the drop is not allowed (another set, a folder under an item, something under itself). Only Editors can drag. In List view, grab the ⠿ handle at the start of a row. Dragging is offered while the list is in its own order: with a sort or a filter on, use the Actions menu or **Move to…**. If several rows are ticked and you drag one of them, all ticked items move together, last in the destination.

The **Actions** menu (Move up, Move down, Move to…) does the same without a mouse.

## Changing many items

In List view, tick the items to change. The box in the header ticks every item shown. Then choose:

- **Set a field…** gives one field the same value on every ticked item. Fields that take several values (“Pick several”) are included. Leave the value empty to clear the field. The same cells are editable in List view's edit mode, one row at a time. Each item that does not have that value yet gets a new version; nothing else about it changes. Add a reason if you like: it shows in each item's history.
- **Move to…** moves the items into a folder of the same set, or to its top level. They go last, in the order they have now.
- **Delete** removes them from the project. Their history is kept, their IDs are never reused, and each can be restored from **Deleted items**.

Up to 500 items at a time. Either every item is changed or, if one cannot be, none is: the message names the item.

Setting a field is refused while you have an unsaved draft of one of the items. Save or discard the draft first.

## Dark mode

The button left of your name in the top bar switches between light and dark. Until you choose, the app follows your computer's setting. Printing always uses light.
